# 予測エラー・警告

- 文書状態：初版案
- 版数：0.4
- 作成日：2026年8月28日
- 更新日：2026年8月28日
- 対象システム：ECモール統合分析システム「Mall Insight」
- 参照資料：[要件定義書](../要件定義書.md) FR-018、第12.2節、第13章

本書は、需要予測の算出で処理エラーまたは警告として扱う条件を定める。取込側のエラー・警告は[取込エラー・警告（販売実績）](../販売実績取込要件/06.取込エラー・警告.md)および[取込エラー・警告（在庫）](../商品在庫取込要件/06.取込エラー・警告.md)に定める。

エラーは、処理を継続しても意味のある結果が得られない場合に用いる。警告は、結果を出したうえで担当者の確認を促すために用いる。いずれも欠損や算出不能を0として黙って処理しない（[要件定義書 第12.2節](../要件定義書.md)）。

## 1. 処理全体のエラー

次の場合は月次予測更新を実行せず、予測バージョンを作成しない。

- 期間別重みの合計が1でない（[03 第4章](03.平均日販.md)）。
- 年度別重みが1件も設定されていない、またはすべて0である（[04 第4章](04.季節係数・トレンド係数.md)）。
- 予測に利用する実績年数が0または負である。
- 主要選択指標がMAE、WAPE、MAPEのいずれでもない。
- 対象実績の取込が1件も完了していない。
- 対象品番の選定バージョンが未確定、対象品番が20件を超過、または選定品番と対象SKUの対応を確定できない。
- 同じ暦月の月次予測更新が既に正常完了している（[08 第4.3節](08.予測バージョンと月次更新.md)）。

## 2. SKU単位のエラー（予測不能）

次の場合、予測対象である当該SKUの予測値を出力せず「予測不能」とする。他の対象SKUの処理は継続する（[07 第8章](07.実績不足時の補完と例外商品.md)）。対象外品番のSKUおよび商品マスタ未登録SKUについては、予測不能レコード自体を作成しない。

- 30日・60日・90日のすべての期間で平均日販を算出できず、新商品の代替手段（手動初期予測、類似商品、初回投入計画）も設定されていない。
- 補正済み実績の算出対象期間の半分以上が欠品日または販売停止日として除外される（[02 第4.4節](02.予測用実績の補正.md)）。
- 所属品番およびカテゴリーのいずれからも予測方式を決められず、既定モデルも適用できない。
- 商品マスタに発売日・終売日の矛盾がある（終売日が発売日より前である）。

予測不能の件数と理由の内訳を、月次予測更新の完了時に表示する。

## 3. 実績データに関する警告

| 条件 | 内容 |
| --- | --- |
| 異常値の候補を検出した | 中央値の5倍かつ10個を超える日がある。除外・置換・採用を担当者が選ぶ（[02 第6章](02.予測用実績の補正.md)） |
| 日次推定在庫が0以下の期間がある | 在庫確認値の入力を促す。確認値が0以下の場合は、確認日を開始日とする欠品期間の登録も促す（[02 第4.3節](02.予測用実績の補正.md)） |
| 確度`入荷済`の入荷予定に補充実績が登録されていない | 実際の在庫増加を日次推定在庫へ反映できない。元の入荷予定から補充実績の登録を促す（[02 第4.2節](02.予測用実績の補正.md)） |
| 日次推定在庫が0以下となった期間に補充実績の登録がない | 推定在庫が実際の在庫を下回っている可能性がある。在庫確認値または不足している補充実績の登録を促す（[02 第4.3節](02.予測用実績の補正.md)） |
| 販売可能日数が最低販売可能日数未満の期間がある | 当該期間を除外し、重みを再正規化した（[03 第5章](03.平均日販.md)） |
| 手動調整数量が入力された明細が対象期間に含まれる | 返品・返金の反映により、実績が変動している |

## 4. 係数に関する警告

| 条件 | 内容 |
| --- | --- |
| 季節係数の12か月合計が12（構成比表現で100%）と一致しない | 正規化して使用し、正規化前後の値を表示する（[04 第5章](04.季節係数・トレンド係数.md)） |
| 季節係数をカテゴリーから補完した | 品番でも実績が不足している。補完階層と補完元を表示する（[07 第4章](07.実績不足時の補完と例外商品.md)） |
| 季節係数の使用年数が最低有効年数ちょうどである | 係数が安定していない可能性がある |
| トレンド係数が上下限で丸められた | 丸め前の値を併記する（[04 第7.2節](04.季節係数・トレンド係数.md)） |
| トレンド不能により候補モデルを除外した | 除外したモデル名を表示する |

## 5. モデル選択・精度に関する警告

モデル選択に関する警告は品番単位で記録する（[06 第3章](06.バックテストとモデル選択.md)）。

| 条件 | 内容 |
| --- | --- |
| 品番として評価可能な起点が最低評価件数に満たない候補がある | 除外した候補と件数を表示する（[06 第7章](06.バックテストとモデル選択.md)） |
| 品番で方式を決められず、カテゴリー単位の方式または既定モデルを採用した | 適用階層と選択理由を記録し、一覧で抽出できるようにする（[06 第3.3節](06.バックテストとモデル選択.md)） |
| 品番WAPEが精度警告の閾値を超えた | 次回の月次予測更新で切替候補を提示する（[06 第10章](06.バックテストとモデル選択.md)） |
| 前回版から品番の選択モデルが変わった | 変更前後のモデルと精度、影響を受けるSKU数を表示する |
| 前回版から予測値が大きく変動した | 変動の大きいSKUを一覧で確認できるようにする（[08 第4.2節](08.予測バージョンと月次更新.md)） |
| バックテストが一部の品番で失敗した | 失敗件数と再実行の導線を表示する |

## 6. 利用時の警告

| 条件 | 内容 |
| --- | --- |
| 予測バージョンの基準日からの経過日数が閾値を超えた | 古い予測で在庫試算を実行しようとしている（[08 第4.4節](08.予測バージョンと月次更新.md)） |
| 在庫試算の選定バージョンと予測バージョンの選定バージョンが一致しない | 対象SKUを過不足なく予測できないため、試算を実行しない |
| 選定変更で追加された品番の予測が未完了である | 当該選定バージョンに対応する完全な予測版が確定するまで、試算を実行しない |
| 在庫試算の対象品番に予測不能のSKUが含まれる | 試算実行時に対象SKUを一覧で表示する |
| 手動予測補正が適用された予測を使用している | 補正の有無、補正前後の値および理由を表示する（[05 第7章](05.予測モデルと需要予測の算出.md)） |
| 予測誤差率の分母が0である | 「算出対象外」と表示し、0除算しない（[06 第10章](06.バックテストとモデル選択.md)） |
| 上位集計に予測不能のSKUが含まれる | 合計値に含まれないSKU数を明示する |

## 7. 表示の原則

- 算出できない値を0、空欄または「-」だけで表示しない。「予測不能」「算出対象外」の状態と理由を表示する。
- 警告を色だけで表現しない。数値、記号または文言でも判別できるようにする（[要件定義書 第6章](../要件定義書.md)）。
- 警告は予測バージョンに紐づけて保存し、後から当時の警告内容を確認できるようにする。

## 8. 未確定事項

1. 警告を予測バージョンに紐づけて保存するか、取込指摘と同様の一覧データとして保存するか。
2. 警告の一覧を、取込指摘一覧（PG-140）に統合するか、需要予測側に別画面を設けるか。
3. 警告件数が多い場合の抑制方法。全対象SKUで同種の警告が発生した場合に、SKU単位ではなく集約して表示するか。
