# 取込エラー・警告

- 文書状態：確定版
- 更新日：2026年8月31日
- 対象システム：販売実績管理システム

本書は、販売実績取込で取込エラーまたは警告として扱う条件を定める。  
検出した内容を記録する取込指摘の保存項目は[販売実績保存データ 第6章](04.販売実績保存データ.md)に定める。

取込エラーは、対象範囲に応じてファイル全体、注文単位、行単位の3種類とする。  
警告は、可能な範囲で登録したうえで担当者の確認を促すために記録する。

## 1. ファイル全体の取込エラー

次の場合はファイル全体を登録せず、取込エラーとして記録する。

- ファイルの文字コードまたは区切り文字を判定できない。
- 対象ファイル種別に必要な必須列が存在しない。
- ファイル種別または取込元を識別できない。

## 2. 注文・行単位の取込エラー

次の場合は該当注文の販売注文および販売注文明細を登録・更新せず、注文単位の取込エラーとして記録する。該当しない他の注文は取込処理を継続する。

- BOSSの`商品合計金額`と、[BOSS受注実績取込要件 第7章](02.BOSS受注実績取込要件.md)の重複判定を適用した後の取込対象明細について算出した税込換算後の明細金額の合計が一致しない。
- Amazonファイルの同一注文内で`purchase-date`が一致しない。

次の場合は対象行を登録せず、行単位の取込エラーとして記録する。正常な他の行は取込処理を継続する。

- 販売実績対象行に、[BOSS受注実績取込要件 第2章](02.BOSS受注実績取込要件.md)または[Amazon全注文レポート取込要件 第2章](03.Amazon全注文レポート取込要件.md)で値を必須とした列の値が存在しない。
- 注文を識別できない。
- 注文明細を識別できない。
- 日時、数量、金額の形式が不正である。
- Amazonファイルの同一注文内に同一明細キーが複数存在する場合の、2行目以降の重複明細。
- BOSSの`倉庫`またはAmazonの`fulfillment-channel`から出荷倉庫を判定できない。
- BOSSの`ショップID`が5桁の半角数字でない、または[BOSS受注実績取込要件 第5章](02.BOSS受注実績取込要件.md)の対応表に存在しない。
- BOSSの`注文ステータス`が`完了`以外である。

[Amazon全注文レポート取込要件 第3章](03.Amazon全注文レポート取込要件.md)によりマルチチャネル出荷注文として取込対象外としたAmazonの行は、本章の行単位の取込エラーの対象としない。

## 3. 警告

次の場合は可能な範囲で登録し、確認用の警告を記録する。

- BOSSの同一注文内に同一商品IDの明細が複数行存在し、最初の1行を除く重複明細を取込対象外とした。
- Amazonの`asin`がSKUマスタの子ASINに存在しない。当該明細は未対応ASINとして記録し、システム内商品コードを未設定のまま可能な範囲で保存する。
- Amazonの`asin`が複数の有効SKUに登録されている。商品コードを確定せず、重複しているSKUを指摘内容に記録する。
- Amazonファイルに想定外の`order-status`または`item-status`が含まれている。
- Amazonの`sales-channel`が空欄、または`Amazon.co.jp`および`Non-Amazon`以外の値である。
- Amazonの`order-status`と`item-status`に矛盾がある。
- Amazonの保存済みの注文・明細を再取込時の対象外ステータスにより無効化した。
- Amazonで対象外だった保存済みの注文・明細を販売対象ステータスにより再有効化した。
- 手動修正が設定されている販売注文明細を再取込で更新した。
- 0円商品が含まれている。
