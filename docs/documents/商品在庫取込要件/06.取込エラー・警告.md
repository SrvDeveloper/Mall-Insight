# 取込エラー・警告

- 文書状態：改訂案
- 更新日：2026年10月1日
- 対象システム：商品在庫管理システム

本書は、商品在庫取込で取込エラーまたは警告として扱う条件を定める。  
検出した内容を記録する取込指摘の保存項目は第4章に定める。

取込エラーは、対象範囲に応じてファイル全体と行単位の2種類とする。  
警告は、可能な範囲で登録したうえで担当者の確認を促すために記録する。

## 1. ファイル全体の取込エラー

次の場合はファイル全体を登録せず、取込エラーとして記録する。

- ファイルの文字コードまたは区切り文字を判定できない。
- [日次在庫CSV取込要件 第2章](02.日次在庫CSV取込要件.md)の必須列が存在しない。
- データ行が1行も存在しない。

## 2. 行単位の取込エラー

次の場合は対象行の4倉庫区分の在庫数をいずれも登録せず、行単位の取込エラーとして記録する。正常な他の行は取込処理を継続する。

- `date`、`sku`または4倉庫区分の列のいずれかの値が空欄である。
- `date`が`YYYY-MM-DD`形式の日付として解釈できない。
- `date`が未来日である。
- 4倉庫区分の列のいずれかが整数として解釈できない。
- 同一ファイル内に同一の`date + sku`が複数存在する場合の、2行目以降の重複行。

## 3. 警告

次の場合は可能な範囲で登録し、確認用の警告を記録する。

- 販売可能在庫が負値である。`0`へ補正せず登録する。
- 直前の在庫基準日に存在したSKUが、当該在庫基準日に存在しない。既存レコードは削除も`0`への書き換えもしない。
- 取得区分が`手入力`の既存レコードと同じ在庫基準日・倉庫区分・SKUを含むファイルを取り込んだ。手入力のレコードは上書きしない。
- 取込済みの在庫基準日の値を、異なる値で更新した。更新前後の値を詳細値に記録する。

在庫試算の対象SKUの在庫未取得および在庫鮮度の超過は、取込時ではなく在庫試算の実行時に警告する（[商品在庫保存データ 第7.1節](03.商品在庫保存データ.md)）。

## 4. 取込指摘

エラーおよび警告は、画面表示だけで終了させず、次の項目を保存する。

| 保存項目 | 内容 |
| --- | --- |
| 取込指摘ID | システムが付与する内部ID |
| 取込履歴ID | 指摘を検出した取込履歴 |
| 重要度 | `エラー`または`警告` |
| 対象単位 | `ファイル`または`行` |
| 指摘コード | システム内で定義する指摘種別コード |
| 指摘内容 | 利用者向けの説明 |
| 元ファイル行番号 | 該当する入力行。ファイル全体の指摘および消失の警告では`NULL` |
| 在庫基準日 | 特定できた場合の在庫基準日 |
| 倉庫区分 | 特定できた場合の倉庫区分 |
| システム内商品コード | 特定できた場合のシステム内商品コード |
| 詳細値 | 更新前後の値、重複件数、不正な値等 |
| 記録日時 | 指摘を記録した日時 |

保存項目の構成は[販売実績保存データ 第6章](../販売実績取込要件/04.販売実績保存データ.md)の取込指摘と共通とし、在庫に固有の項目として在庫基準日および倉庫区分を追加する。
