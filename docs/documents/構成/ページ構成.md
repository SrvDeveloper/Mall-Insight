## 1. 目的と範囲

本書は、[要件定義書](../要件定義書.md)の機能要件および画面要件、ならびに販売実績・商品在庫の各取込要件を、画面の単位へ割り付けた一覧を定める。画面ごとの目的、主な表示項目、主な操作および関連要件を示すことを範囲とし、項目の型、桁数、レイアウトおよび遷移パラメータは詳細設計で定める。

## 2. 画面構成の方針

1. 「実績」「年間販売目標」「システム需要予測」は同一画面に並べて表示する場合も別項目として扱い、相互に上書きしない。
2. 在庫試算に関わる画面には、需要値がシステム需要予測であることを明記する。
3. 計算値を表示する画面では、使用データ、計算式、算出日時および版を確認できる導線を設ける。
4. 在庫は倉庫区分単位で表示し、合計在庫は表示上の派生値として明示する。
5. 欠損、鮮度超過および算出不能を0として表示せず、「算出対象外」「予測不能」等の状態と警告を表示する。
6. 確定した版（目標版、予測バージョン、選定バージョン）と、最新データによる在庫試算結果を画面上で区別する。
7. 画面IDは分類ごとに10刻みで採番し、既存IDの再利用および振り直しをしない。

## 4. 画面遷移

主要な業務導線は次のとおりとする。取込から在庫試算までを日次・月次の運用順に配置する。

```text
PG-010 ダッシュボード
 ├─ 日次  PG-110 販売実績取込 → PG-130 取込履歴 → PG-140 取込指摘一覧 → PG-810 商品・SKUマスタ
 ├─ 随時  PG-120 商品在庫取込 → PG-130 取込履歴 → PG-610 在庫照会
 ├─ 月次  PG-810 商品・SKUマスタ → PG-710 対象品番選定
 ├─ 月次  PG-710 対象品番選定 → PG-310 需要予測一覧 ┬→ PG-330 予測精度検証
 │                                                   └→ PG-320 手動予測補正
 ├─ 年次  PG-710 対象品番選定 → PG-410 年間販売目標入力・改訂 → PG-420 目標改訂履歴
 ├─ 随時  PG-510 販売目標・予測・実績比較 → PG-520 品番・SKU詳細
 ├─ 随時  PG-630 発注・入荷予定管理
 └─ 月次  PG-310 需要予測一覧 ┬→ PG-730 12か月在庫推移
                              └→ PG-740 欠品・推奨発注一覧
```

- PG-520は、PG-210、PG-310、PG-510、PG-610およびPG-740から品番またはSKUを指定して遷移できる共通の詳細画面とする。
- PG-630は、PG-730およびPG-740から対象SKUを引き継いで遷移できる。

## 5. 共通仕様

| 項目 | 内容 |
| --- | --- |
| 共通ヘッダー | 対象年度、基準日、利用者および権限を表示する |
| 絞り込み | 一覧画面は品番、SKU、カテゴリー、モール、倉庫区分および販売状態で絞り込める |
| 値の区別 | 自動取得値、手入力値、計算値および上書き値を書式または記号で識別する |
| 差異表示 | 目標対予測差等は、色、アイコンまたはバーに加え、数値または記号でも状態を判別できるようにする |
| 鮮度表示 | 在庫を使用する画面は、倉庫区分ごとの在庫基準日と経過日数を表示し、許容日数の超過を警告する |
| 算出不能 | 分母0、実績不足および参照欠損は「算出対象外」または「予測不能」と表示し、0として表示しない |
| 根拠表示 | 計算値は、使用データ、計算式、算出日時および版を確認できる |
| 丸め | 途中値は小数精度を保持し表示時に丸める。発注数量は最終段階でのみ切り上げる |
| CSV | 一覧はCSV出力できる。年間販売目標および子ASINを含むSKUマスタはCSV入力にも対応する |
| 非同期処理 | 大量再計算は非同期実行とし、処理状態と完了を確認できる |
